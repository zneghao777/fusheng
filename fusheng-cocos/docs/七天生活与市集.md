# 七岁到三十岁的纸片人生

新档从7岁开始。七个游戏日代表一岁，每天恢复三格心力。完整游玩24年、
共168个游戏日后，30岁这一周进入“敬请期待”终页。不会进入31岁，也不会
强制清空房间或自动开启下一代。

## 五个人生阶段

| 年龄 | 阶段 | 主要活动 | 生活安排 |
| --- | --- | --- | --- |
| 7—12岁 | 童年 | 学校功课、自然观察、家庭家务 | 家人支持生活和画材，陪同社区绘画练习与亲子义卖 |
| 13—17岁 | 少年 | 专注学习、绘画社团、社区志愿 | 平衡升学、兴趣和关系，家人继续支持生活 |
| 18—23岁 | 青年 | 课程进修、职业实践、独立生活 | 正式管理预算、接受委托，工作活动获得收入 |
| 24—29岁 | 成年 | 职业工作、个人创作、陪伴重要的人 | 在事业、创作和关系间安排时间，继续经营小屋 |
| 30岁 | 中年序章 | 整理经验、完成代表作、照顾重要关系 | 完整过完七天，再回看人生并进入终页 |

顶栏手账中的 **安排学习与生活** 打开当前阶段活动。每项每天一次，
消耗一格心力和九十分钟；执行前展示效果，心力不足或时间太晚不会扣资源。
实际收入、成长积累和方向加成以面板为准。

7、12、13、17、18、23、24、29、30岁有关键选择。先查看三个方向，
再打开详情确认；确认后不能重复领取奖励。选择会增加学习、创作、陪伴或职业积累，
并改变后续适用活动的收益。以后阶段可以重新选择方向。

## 一岁中的七天

1. 周一打开手账安排学习和生活，向街坊了解绘画项目。
2. 周二结束前选定小林或叶婆婆的一份项目；取材和创作各用一格心力。
3. 周三带符合题材、风格和成色要求的画当面交付，用一格心力和180分钟。
4. 可以和街坊认真聊天、赠画、答应老周的备摊约定。
5. 最迟周五用两格心力和240分钟完成已经答应的帮忙。
6. 整理画夹，选最多三幅作品预留到周日。
7. 周日10:00—20:00参加展出或市集；休息后整理年度记录，再长大一岁。

这些是建议路线。错过委托或市集会留下后果，但不会卡住成长。
周日提前休息会先说明错过市集的结果，再由玩家决定。

## 创作、街坊和市集

| 题材 | 获得方法 |
| --- | --- |
| 窗边日常 | 开局已有 |
| 旧巷灯火 | 巷口取材 |
| 池塘倒影 | 公园池塘 |
| 梧桐树影 | 公园长椅 |
| 旧书与信 | 旧书店翻书 |
| 街坊肖像 | 和老周认真聊天 |

每幅作品需要一格心力和150分钟。18岁后需六文画材，未成年人由家人支持。
取材增加两点灵感，最多六点；下一幅画使用一点灵感提高成色。
书架提高水墨成色，茶桌提高留白成色。

作品可出售、当面赠送、留作展出或挂墙。作品墙有三格，更换后原作回画夹。
同一作品只会归属一处。每位街坊每年接受一次赠画，喜欢的题材带来更多信任和纪念物。

小林的项目要求暖色街巷，叶婆婆的项目要求水墨旧书，成色至少45。
儿童材料奖励分别35文、30文；少年社团奖励50文、45文；成年委托100文、90文。
同一周三的两份项目只能选一份。失约扣信任，之后仍可继续生活。

老周的备摊约定每年重新开放。今年完成后，今年的市集获得帮助；下一岁留下
台灯与生活回声，不会把“完成”状态永久沿用。成人达到信任要求后可以借60文，
只能留一笔未还借款，跨年未还会降低信任。未成年人没有借贷入口。

周日提前到达会等待至10点。没有预留时从画夹取前三幅，挂墙的作品需先收起。
三位访客有不同喜好和预算，可以调整价格、保留作品或提前收摊。
成交、收摊只结算一次，未售作品仍属于玩家。

## 年结和最终结局

每年记录成长积累、完成作品、交易和重要选择。进入下一岁保留作品、家具、
纪念物、人物信任与记忆；市集主题轮换，委托与备摊重新开放。
旧18岁周存档从当前年龄继续，不倒退为7岁，也不伪造童年记录。

30岁周日先完成日结与年结，再整理人生相册进入终页。终页可以逐层回看
各阶段年份、重要选择、保留的代表作品和街坊记忆，并保存返回标题。
游戏时间和资源在终页冻结。退出后读档仍回到终页，后续人生显示“敬请期待”。

## 操作、画面和存档

桌面鼠标点地面走动，点家具或人物会走近互动。A/D走动，W/S爬梯，空格跳跃，
E互动，J手账，I画夹，C人物，B布置，Esc返回或打开菜单。
旧书店有上下两层，点击楼上目标会自动经右侧木梯上下楼。

手机以横屏游玩。竖屏显示清楚的转屏引导，横屏后自动继续。点击空地走路，
点击物品会走近互动，跨楼层自动上下木梯，不显示遮挡场景的方向键。右下保留
透明底的跳跃与情境互动按钮，顶栏按钮保持可见。创建角色无需滚动；通用面板左侧只滚动正文，
右侧操作使用上一页、下一页切换。开始、继续、确认与返回不藏在正文底部。

菜单第一页左下固定显示**回到开始界面**，其他菜单页也保持可见；返回前保存进度。

便利店和书店显示可见的街坊人物；公园、店铺与街口有对应真实交互位置的门与纸签。
场景纸签使用透明底、细角框和宋体小字，室外字色随昼夜切换，地面短线标识入口。
手机仅在右下显示情境互动，
不在人物上方重复覆盖操作牌。
周日市集显示摊棚、挂画与访客，区分准备、营业、散场。角色随年龄逐步长大，
30岁使用成年形象。

新档进入纸屋展开动画，日常读档推门回家，跨年使用手账翻页。
动画可跳过，减少动态效果时使用简短过渡；后台暂停，不推进时间或重复结算。

自动存档、三个存档槽、备份恢复和FS1存档码继续可用。新人生字段会验证
年龄、选择、年表、资源及结局状态。旧经典存档继续原玩法，到30岁也显示统一终页。
