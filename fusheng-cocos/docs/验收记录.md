## 交付与环境

- 工程：Cocos Creator **3.8.8**，使用本机正式编辑器命令行构建。
- 产物：`build/web-desktop/`、`build/web-mobile/`，均为独立静态站点。
- TypeScript strict；core 为纯 TS；0.1 秒固定步长；Command / SimEvent。
- UI 为 Cocos prefab / Label / Button / ScrollView / Mask / EditBox；
  场景、家具、人物由 Cocos Graphics 绘制。浏览器原生输入框仅由 Cocos EditBox 管理。
- 旧 HTML 的 SHA-256 保持
  `964c6901b6b4242106eb1ef5bca460cd2a0d63c9947007e9ee40cfb0c5e1dd1d`。
- 未初始化 Git，未提交或推送，未部署。

## 运行与补验

```sh
cd fusheng-cocos
npm run serve
```

桌面：<http://127.0.0.1:8088/web-desktop/>。
同 Wi-Fi 手机：<http://192.168.1.105:8088/web-mobile/>，IP 改变时使用电脑当前局域网地址。
这只是本地静态服务，没有发布到公网。

补验时依次检查：竖屏进入提示、横屏走/爬/跳/互动、面板手势滚动、布置轻点/长按、
三个存档槽、存档码复制粘贴、切后台恢复，以及持续游玩帧率。
