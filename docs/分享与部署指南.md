# 不买服务器，怎么把《浮生》发给朋友玩

> 结论：这款游戏是**纯静态单文件**（`game/index.html`，约 160KB，无后端、无数据库、无外部资源），
> 任何静态托管都能放。你不需要买服务器，只需要一个能放 HTML 的地方，然后把链接发出去。

---

## 0. 先明确三件事

1. **朋友点开链接就能玩**：手机横屏已适配触屏（左下方向键，右下菜单/跳/互动）；桌面用键鼠。
2. **存档在各自浏览器里**：`localStorage`，按域名隔离。朋友玩他们的，你玩你的，互不影响。
3. **没有云存档**：清缓存、换手机、换域名都会丢档。分享前先定好最终链接，别中途换地址。

---

## 1. 方案对比：先选一条路

| 方案 | 费用 | 国内/微信访问 | 上手难度 | 适合 |
|---|---|---|---|---|
| **GitHub Pages** | 免费 | 一般，时快时慢；微信内可能提示「非官方网页」 | 需要 GitHub 账号 | 零成本、顺便做版本管理 |
| **腾讯云 CloudBase 静态托管** | 有免费额度/按量计费 | **好**，国内 CDN，默认子域名一般免备案 | 需腾讯云实名 + 开环境 | 朋友都在国内/微信，想稳 |
| **Netlify Drop** | 免费 | 不稳定，时快时慢 | 拖拽，1–5 分钟 | 现在就要发出去试玩 |
| **EdgeOne Pages** | 免费 | 默认域名在中国大陆受限：预览链接 3 小时有效，或需绑定已备案域名 | 中 | 有备案域名时再考虑 |
| **Vercel** | 免费 | **国内大面积不可访问** | 低 | 不要用于国内分享 |
| **Gitee Pages** | — | 已下线 | — | 不要用 |
| **对象存储 COS/OSS** | 几元/月 | 好，但配置略麻烦；自定义域名需备案 | 中高 | 有云账号、愿意折腾 |
| **微信直接发 HTML 文件** | 免费 | 不可靠，iOS 常当文本预览 | 低 | 不要用 |

**推荐组合：**

- 想**零成本、长期、可版本管理** → GitHub Pages（方案 A）。
- 朋友都在**国内/微信**，想打开稳定 → CloudBase 静态托管（方案 B）。
- 只想**5 分钟先发出去** → Netlify Drop（方案 C），不行再换 B。
- 想要短链/品牌感 → 买个域名（约 ¥30–80/年）+ 备案（免费，1–20 个工作日），仍然不需要服务器。

---

## 2. 方案 A：GitHub Pages（零成本，推荐先做）

### 步骤

1. 注册/登录 GitHub。
2. 新建一个 **public** 仓库，名字随意，比如 `fusheng`。
3. 把 `game/index.html` 上传到仓库**根目录**（文件名必须是 `index.html`）。
4. 仓库 → **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)**
   - 点 **Save**
5. 等 1–2 分钟，访问：
   ```
   https://<你的用户名>.github.io/fusheng/
   ```
   如果仓库名是 `<用户名>.github.io`，地址则是 `https://<用户名>.github.io/`。

### 更新

- 直接重新上传/覆盖 `index.html`，或 `git push`；Pages 会自动重建。
- 同一个地址更新，朋友的存档会保留（localStorage 按域名隔离）。

### 注意

- 免费版 Pages 要求仓库 **public**。
- 国内访问 GitHub Pages 有时慢、有时打不开；微信内可能先弹「非微信官方网页」，点继续即可。
- 如果 404：等 1–2 分钟；确认文件在根目录、名字是小写 `index.html`。
- **换仓库名/换账号会换域名，旧存档不跟随**。

---

## 3. 方案 B：腾讯云 CloudBase 静态托管（国内/微信更稳）

> 这是「不买服务器」里最适合国内分享的一条：你用的是静态托管 + 国内 CDN，不是云服务器。
> 控制台菜单可能改版，认准「静态网站托管」即可。

### 步骤

1. 注册腾讯云账号，完成**实名认证**。
2. 开通 **云开发 CloudBase**，创建一个环境（按量计费/免费额度，具体以控制台为准）。
3. 进入环境 → **静态网站托管** → 上传 `index.html` 到根目录。
4. 设置**索引文档**为 `index.html`（默认首页）。
5. 使用平台分配的默认域名，形如：
   ```
   https://<环境ID>.tcloudbaseapp.com/
   ```
   默认子域名一般**不需要 ICP 备案**；绑定自己的域名才需要备案。
6. 把链接/二维码发给朋友。

### 注意

- 访问量很小（每次约 160KB），朋友级别的流量成本接近 0；但仍要留意免费额度/计费规则，以控制台「资源包与额度」为准。
- 国内 CDN，微信内打开通常比 GitHub Pages 稳。
- 自定义域名需要 ICP 备案；不备案就用默认子域名，完全够分享。
- 如果只想快速试，不想实名，先用方案 C。

---

## 4. 方案 C：Netlify Drop（5 分钟，最快）

### 步骤

1. 打开 <https://app.netlify.com/drop>。
2. 把包含 `index.html` 的文件夹（`game/`）直接拖进去。
3. 等几秒，得到一个 `https://<随机名>.netlify.app` 地址。
4. 注册/登录 Netlify 并 **Claim site**，这个站点才会长期保留。
5. 更新：再拖一次新文件夹，或覆盖部署。

### 注意

- 国内访问不稳定，时快时慢；适合先给朋友试玩，不适合作为长期主站。
- 如果朋友打不开，换方案 B。

---

## 5. 怎么发给朋友

### 直接发链接

微信里把链接发出去，朋友点开就在微信内置浏览器里运行。第一次加载约 160KB，正常网络秒开。

### 发二维码

- 用「草料二维码」等工具把链接生成二维码，发图片；朋友扫一下就能进。
- 或者本机装 `qrencode`：
  ```bash
  brew install qrencode
  qrencode -o fusheng.png "https://你的链接"
  ```

### 微信里的两个小技巧

1. 右上角 **··· → 在浏览器打开**：全屏更彻底、性能更好，也方便横屏。
2. iOS Safari 可 **分享 → 添加到主屏幕**，之后像 App 一样全屏打开（已加 `apple-mobile-web-app-capable`）。

### 手机怎么玩

- 游戏是 16:9 横屏设计；竖屏会显示「把手机横过来」，也可以点「仍然竖屏进入」降级玩。
- 左下方向键走/爬梯，右下「菜单 / 跳 / 互动」；互动键会自动变成「睡觉」「画画」「出门」「找人聊聊」。
- 顶栏「人物 / 布置 / 菜单」都可以直接点。
- 布置模式：轻点放置，长按 0.55 秒回收。

## 6. 更新、存档与换地址

| 操作 | 存档会怎样 |
|---|---|
| 同一域名下覆盖 `index.html` | **保留**（localStorage 按域名隔离） |
| 换托管平台/换域名 | **丢失**（新域名是新的存储空间） |
| 朋友清微信缓存/浏览器缓存 | **丢失** |
| 无痕模式/换手机 | **丢失**（各自本地） |
| 同一手机换浏览器 | **丢失**（不同浏览器存储隔离） |

所以：

- **分享前先定好最终链接**，别发出去再换域名。
- 更新游戏只覆盖文件，不要换地址。
- 目前没有云存档；如果以后要跨设备，最省事的下一步是加「导出/导入存档码」（仍然不需要服务器）。

## 7. 常见问题

**打开白屏？**
- 确认是 HTTPS（GitHub Pages / CloudBase / Netlify 都自动 HTTPS）。
- 确认 `index.html` 在根目录，文件名大小写正确。
- 打开浏览器控制台看有没有 404/JS 报错。

**微信提示「非微信官方网页」？**
- 外链常见提示，点继续访问即可。
- 国内备案域名/CloudBase 默认域名通常更少提示；GitHub Pages/Netlify 更容易遇到。

**点开变成下载/显示源码？**
- 多半是对象存储的默认域名或 Content-Type 不对。用静态托管平台，别用 OSS/COS 的裸域名直接放 HTML。

**手机上没有触屏按钮？**
- 确认是手机/平板访问，且横屏；`?touch=1` 可在桌面浏览器强制显示触屏控件做调试。
- 如果仍然没有，检查浏览器是否禁用了 JavaScript。

**按钮太小/挡住场景？**
- 触屏按钮基准是 44–62px，可以在 CSS 里调 `.tpad/.tactions` 的 `--tb`。
- 小屏横屏（如 667×375）会比较紧凑，这是当前版本的已知限制。

**朋友说卡？**
- 先关掉其他 App；低端 Android 可以在后续版本加自动降 DPR/30fps 兜底。
- 微信内建议「在浏览器打开」。

---

## 8. 不想公开代码？

- GitHub Pages 免费版要求 public 仓库；CloudBase/Netlify Drop 不需要公开仓库。
- 但这是前端游戏，任何人打开网页都能看到源码；「不公开仓库」只是不让人搜到仓库，不是防破解。
- 真正需要保护的是后端数据/内购权益；当前版本没有这些。

---

## 9. 一张决策表

| 你的情况 | 选这个 |
|---|---|
| 朋友都在国内/微信，想稳 | **CloudBase 静态托管** |
| 有 GitHub，想零成本 + 版本管理 | **GitHub Pages** |
| 现在就要发，5 分钟 | **Netlify Drop** |
| 有备案域名，想长期品牌 | 域名 + CloudBase / EdgeOne |
| 只想同一 Wi-Fi 给身边人演示 | 本机 `python3 -m http.server`（见下） |
| 看到 Vercel / Gitee Pages 教程 | 跳过，前者国内不可用，后者已下线 |

### 附：同一 Wi-Fi 下的临时演示（不算分享到外网）

```bash
cd game
python3 -m http.server 8000
ipconfig getifaddr en0        # 拿本机局域网 IP，比如 192.168.1.23
```

同一 Wi-Fi 的朋友访问 `http://192.168.1.23:8000/` 即可。只适合当面演示，不适合远程分享。

## 10. 最短路径（照着做）

1. 打开 <https://app.netlify.com/drop>，把 `game/` 文件夹拖进去。
2. 拿到 `https://xxx.netlify.app` 链接，自己手机先横屏试一局。
3. 没问题就把链接发群里；朋友打不开，再按方案 B 迁到 CloudBase。
4. 决定长期用哪个地址后，再大量分享；之后只覆盖 `index.html` 更新，不要换域名。
