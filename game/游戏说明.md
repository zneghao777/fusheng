# 浮生 · 纸片屋 v4

一个 2D 侧视的生活模拟小游戏。水墨纸面质感，一间剖开的小屋，从七岁到三十岁。
没有内购，没有体力条逼你上线，没有每日签到——只有吃饭、洗澡、睡觉、画画，和隔壁老周。

## 怎么运行

双击 `index.html` 即可。纯静态单文件，无依赖、无构建、无需服务器。

- Chrome / Edge / Safari 均可（推荐 Chrome）。
- 手机横屏可用：左下方向键，右下「菜单 / 跳 / 互动」；互动键会显示身边物件的动作。竖屏会提示转屏。
- 想发给朋友：把 `index.html` 放到任意静态托管，发链接或二维码即可；见 [../docs/分享与部署指南.md](../docs/分享与部署指南.md)。
- 3 个存档位，存在浏览器本地（localStorage）。清缓存或换域名会丢档。

## v4 新增：三页结构 + 开场叙事

### 一、三个独立页面

原来「标题 + 存档位」挤在一屏，现在拆成三页：

| 页面 | 内容 | 入口 |
|---|---|---|
| **标题页** | 浮生 / 纸片屋 / 印章 | 启动即进 |
| **开始游戏** | 三个存档位，带角色、年龄、周次、住处、存款 | 标题页「开始游戏」 |
| **新建存档** | 先选存档位（占用的不可选），再选性别与角色 | 标题页「新建存档」 |

- 读取页的空位可以直接「在这里新建」，跳到新建页并预选该位置。
- 三个位置都满时，新建页的槽位全部置灰，点「开始这一生」会提示先去删档。
- 所有页面都能「返回」回标题页。

### 二、开场叙事

选完人、按下「开始这一生」之后，不直接进游戏，先走一段**六幕叙事**：

1. 七岁那年的春天
2. 你住在哪（按住宅档位写：三层楼 / 两层 / 单间）
3. 家里的样子（按出身写：负债、单亲、富二代、奶奶带大……各自不同）
4. 你叫什么（角色名 + 一句话性格）
5. 伏笔（这一年看起来会和往常一样）
6. 落版（你今年七岁 / 接下来的二十三年，由你来过）

表现形式：

- 纸面蒙版随每一幕**缓慢抬升**（0.97 → 0.76 → 1.0），第二幕会隐约看见你将要住的那间屋子。
- 每一行文字从下方浮起、去模糊、逐个延迟入场。
- 左侧一道墨线由上至下画出，顶上压一个「序」字。
- 底部进度点随幕次点亮；右上角可「跳过」，点击或空格继续。
- 叙事结束才弹出「投胎结果」面板，把数值交代清楚，然后进游戏。

### 三、户外场景与「出门」修复

四个外景都在：巷口 / 便利店 / 旧书店 / 公园。

但上个版本留了一个断点：家门仍然接在早期版本的「文本选项」上（选去便利店 / 公园 / 书店，只扣时间不换场景），
所以玩家其实**从来没有真正走出过门**。本版把门直接接到巷口：

- 走到门口按 E → 进入巷口（消耗 20 分钟游戏时间）
- 巷口可去便利店 / 旧书店 / 公园，各自的物件都能交互
- 从任何外景回来，会落在自家门口
- 站在门槛上时，「出门」优先于旁边的家具（不会因为挨着淋浴而摸不到门）
- 切换场景有一层 0.45 秒的纸色闪白，避免硬切

## v3 新增：年龄、成长与门第

### 一、一周一岁

游戏按「周」循环：**7 天 = 1 周 = 长 1 岁**。

- 出生时 **7 岁**，每过完一周生日面板自动弹出，年龄 +1。
- 到 **30 岁**这一周结束，这一代收尾，进入传承。
- 顶栏常驻显示：`7 岁 · 第 1 周 · 第 1 天`。
- 日终结算会写清「这一周还剩几天」，周日晚上按钮变成「这一周过完了」。

### 二、三档建模

角色按年龄自动换模型，不是简单缩放：

| 阶段 | 年龄 | 建模差异 |
|---|---|---|
| 小孩 | 7–13 | 整体 74% 身高、头身比更大、腿更短 |
| 青年 | 14–23 | 标准身形 |
| 中年 | 24–30 | 身高略增、肩背更宽、鬓角泛白、外套有门襟 |

选人界面显示的就是你 7 岁的样子；随着年龄增长，屋里走动的人会自己变。

### 三、成长属性

每年生日随机成长，三条属性各有实际作用：

| 属性 | 作用 |
|---|---|
| 体格 | 每点让体力衰减慢 0.8%（最多 25%） |
| 心智 | 每点让技能经验获取 +2% |
| 人缘 | 每点让关系升温 +1% |

生日面板会写清「+1（共 3）」这样的累计值，第 14 岁起人缘开始加速成长。

### 四、按财富换房子

住房不再写死在出身上，而是跟着**家庭财富等级**走，三档严格对应三种建模：

| 财富 | 住宅 | 结构 |
|---|---|---|
| 富裕 | 三层小楼 | 三层、梯子贯穿、吊灯、挂画、三楼栏杆 |
| 小康 | 两层住宅 | 两层、单梯 |
| 贫困 | 单层平房 | 一层通间、无梯、裂缝水渍明管、晾衣绳、裸灯泡 |

出身决定起点（富二代/艺术世家=富裕，普通/独居/重组/奶奶带大=小康，做题家/单亲/城中村/负债=贫困）。

**变化是动态的**：每周生日时结算一次，跨过阈值就搬家——

- 贫困 → 小康：存款 ≥ 450
- 小康 → 富裕：存款 ≥ 1100
- 富裕 → 小康：存款 < 500
- 小康 → 贫困：存款 < 90

阈值带滞回，不会因为买了两顿饭就来回搬。搬家时旧家具折算掉，新住处自带一套，生日面板会告诉你搬去了哪儿。

### 五、事件密度下调

随机事件的每小时触发概率从 17% 降到 **8%**（每天仍最多 2 件），把节奏让给日常和成长。
命定变故改成**每 3 周**重新抽一次，二十多年里不会只遇到一件。

## 核心玩法

**四条状态**：体力 / 饱腹 / 整洁 / 兴致。它们不是"红条警告"，而是效率乘数。

**今日三件事**：每天随机抽 3 个小目标。完成有心情加成和家族声望，不完成也没有惩罚。

**随机投胎**：10 种出身，难度 1–5 星，起始资金、状态、手艺、家具、赚钱效率都不同。

**命定变故**：第 2–5 天砸下来，开局只显示"？？？"。可能是房东涨租、医院来电，也可能是中奖、猫赖着不走。

**传承**：三十岁那年选一条家训，效果永久叠加到下一代，下一代重新从 7 岁开始。

## 已实现的系统

- 年龄 7–30、按周推进、三档建模、三条成长属性
- 三档住宅按财富动态切换（三层 / 两层 / 单层），搬家与家具重置
- 时间：连续 tick，1 秒 = 12 游戏分钟；日夜光照与窗景
- 需求衰减 + 情绪二维模型（效价 × 唤醒）+ "为什么"归因
- 14 件家具、13 种互动、技能经验与升级（绘画 / 烹饪 / 社交）
- 老周：9:00–21:00 在家，4 种话题
- 8 个随机事件 + 8 个命定变故 + 3 个剧情节点 + 每日配额
- 建造模式：6 种可购家具、网格吸附、碰撞校验、六成回收
- 四个外景：巷口 / 便利店 / 旧书店 / 公园
- 3 个存档位、手动保存、自动保存、旧档迁移
- 日终结算 + 生日成长 + 搬家 + 传承 + 分档结局文案

## 明确没做的

30 岁之后的老年阶段、死亡与遗产分配、完整遗传与捏脸、多人联机、宠物、天气季节、
玩家 UGC 分享、移动端竖屏完整布局、音频、成就系统。

## 设计取舍

1. **一周一岁而不是一天一岁**：7 天足够跑完一个完整的小循环（吃饭、洗澡、画画、社交），
   年龄增长才有"又过了一年"的重量，而不是刷数字。
2. **成长属性必须有用**：三条属性分别挂在体力衰减、经验获取、关系升温上，不做纯展示数值。
3. **财富决定房子，而不是出身决定房子**：出身只给起点，之后靠自己赚。
   三档房型在层数上一眼可辨，玩家不用读数值就知道自己混得好不好。
4. **搬家会重置家具**：既是代价也是奖励，省去"旧家具怎么搬过去"的一整套系统。
5. **事件概率调低**：一局二十多周，事件太密会变成噪音。日常的呼吸感比意外更重要。
6. **到 30 岁收尾**：这一版只做人生前半段，留给后续版本扩展老年与死亡。

## 调试参数（可选）

- `?skip=1` 跳过开始界面，直接开一局
- `?screen=create` 直接看选人界面
- `?house=villa|flat|rental` 指定住宅（三层 / 两层 / 单层）
- `?age=25` 指定年龄（同时推算周数）
- `?scene=street|park|store|book` 指定场景
- `?hour=22` 指定时间
- `?portrait=1` 三档建模对照图
- `?panel=origin|char|help|build|summary|legacy|event|pause|birthday` 直接打开对应界面
- `?screen=load` 直接看读取存档页
- `?panel=prologue&beat=2` 直接看第 N 幕叙事
- `?at=door` 开局站在门口（验证出门）
- `?selftest=1` 跑核心逻辑自测
- `?flow=1` 跑「选人 → 开局 → 存档」流程自测
